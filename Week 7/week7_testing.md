# Week 7 - Testing and Evaluation

## 1. Objective

The objective of Week 7 is to test and evaluate the
Resume Job Matching Platform.

The system is tested for:

- Functional correctness
- Matching behavior
- Input validation
- Edge cases
- API behavior
- Overall reliability

The following functionalities were tested:

- Resume processing

- Empty resume

- Short resume
- Special characters
- No matching skills
- Unrelated resume
- Invalid file
- Large file

API behavior was tested with:

- Valid input
- Missing input
- Invalid input
- Successful response
- Error response
