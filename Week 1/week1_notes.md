## What I Learned

### 1. Pandas
Pandas is a Python library used to load, manipulate, and analyze datasets.

Functions used:
- read_csv()
- info()
- isnull()
- fillna()
- to_csv()

---

### 2. Features

Features are the input variables used by a Machine Learning model.

Example:
- Skills
- Experience
- Education

These values help predict the job role.

---

### 3. Labels

Labels are the output values that the model predicts.

Example:
- JobRole

---

### 4. Data Cleaning

Data cleaning involves:
- Detecting missing values
- Filling missing values
- Saving the cleaned dataset

This helps prepare data before model training.
