# Week 4 Progress

## Topic Learned

### Intent Design

Intent means the purpose or meaning behind a user's message.

For example:

"Show me suitable jobs"

The intent of this message is `job_match`.

Intent design helps a system understand what the user wants to do.

## Intents Defined

For my Resume Job Matching Platform, I defined the following intents:

- greeting
- upload_resume
- job_match
- skills
- exit

## What I Built

I created a small intent dataset using CSV and loaded it using Pandas.

I also created a Python program to display all the intents and their example messages.
