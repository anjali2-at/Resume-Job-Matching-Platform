# Future Scope

The project can be improved in several ways.

## 1. Advanced NLP

Use advanced NLP techniques to understand the meaning of resume and
job description text.

## 2. Semantic Matching

Use embeddings and transformer-based models to identify similar skills
even when different words are used.

## 3. Resume File Upload

Allow users to upload PDF and DOCX resumes directly.

## 4. More Detailed Scoring

The matching score can consider:

- Skills
- Experience
- Education
- Certifications
- Job requirements

## 5. Larger Skill Database

A larger database can be created containing technical and
non-technical skills.

## 6. Job Recommendations

The system can recommend suitable job openings based on the
candidate's resume.

## 7. Web Application

The project can be converted into a complete web application using
FastAPI and a frontend framework.

## 8. Explainable Results

The system can explain why a particular job received a certain
matching score.
