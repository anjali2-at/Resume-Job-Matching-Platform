# Project Limitations

The current version of the Resume Job Matching Platform has some
limitations.

## 1. Limited Skill Database

The system currently checks skills from a predefined list.

New skills must be added to the database manually.

## 2. Keyword-Based Extraction

Skill extraction mainly depends on finding known keywords in text.

It may not understand the meaning of a sentence completely.

## 3. Basic Matching Score

The matching score is based on the number of matched job skills.

It does not consider:

- Years of experience
- Skill importance
- Education
- Job location
- Salary
- Company requirements

## 4. Resume Format

The current version mainly works with extracted text.

Different resume formats may require additional processing.

## 5. No Advanced Semantic Matching

The current system does not use advanced language models to understand
similar meanings between different words or phrases.
