## Topics Covered

### Linear Regression

Linear Regression is one of the simplest supervised machine learning algorithms. It is used to predict continuous values.

Example:
- Predicting salary based on years of experience.

---

### Train-Test Split

Instead of using the whole dataset for training, I divided it into two parts.

- Training Data (80%)
- Testing Data (20%)

The training data is used to teach the model, while the testing data is used to check how well the model performs on unseen data.

---

### Evaluation Metrics

After training the model, I learned how to evaluate its performance.

The metrics used are:

- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- R² Score

These values help in understanding how accurate the predictions are.
