## Topics Learned

### Text Preprocessing

Text preprocessing means preparing text before giving it to a machine learning model.

Some common steps are removing unnecessary words, converting text into a suitable format and cleaning the text.

### TF-IDF

TF-IDF is used to convert text into numerical values.

It gives importance to words based on how frequently they appear in the text.

### Naive Bayes

Naive Bayes is a machine learning algorithm that can be used for text classification.

I used it to classify messages as spam or ham.

## What I Built

I built a simple spam classifier using:

- Pandas
- TF-IDF
- Naive Bayes

The model takes a message and predicts whether it is spam or a normal message.
